# 1 - version de PowerShell
$PSVersionTable.PSVersion

# 2 - permisividad
Get-ExecutionPolicy

# 3 - edicion del SO
Get-ComputerInfo | Select-Object OsName, WindowsEditionId, OsVersion

# 4 - info completa de la PC (comando del simbolo del sistema)
systeminfo

Aclaracion - Estoy en Linux Mint

En mi equipo Linux Mint 22.3 el comando systeminfo no existe porque es exclusivo de Windows CMD.

Cuando lo ejecuto en PowerShell 7.6.8 Core me da error.

Por eso el equivalente en Linux Mint que use es:

  • hostnamectl -> info completa de la PC
  • uname -a -> version del kernel
  • lsb_release -a -> edicion de Linux Mint
